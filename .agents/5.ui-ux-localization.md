# 🎨 5. 글래스모피즘 디자인 & 로컬라이제이션 스페셜리스트 (Glassmorphism & Localization Specialist)

> **"프로스티드 글래스의 모던한 시각적 품격과 완벽한 모국어 수준의 한국어 인터페이스를 구축한다."**

---

## 🎯 핵심 역할 및 디자인 원칙

### 1. 글래스 디자인 철학 (Glassmorphism & Frosted Glass)
* **문서 캔버스 최우선**: 본문 종이(Paper)의 텍스트 가독성을 최우선으로 보호하며, 상단 리본/사이드바/팝업 창에 정밀한 반투명 블러(Blur)와 입체적 앰비언트 섀도우를 적용.
* **미세 하이라이트 엣지**: 반투명 요소에 `CornerRadius: 6~10px`와 1px 미세 빛 반사선(Specular Border)을 적용하여 입체감 부여.
* **WCAG 4.5:1 명도 대비**: 반투명 상태에서도 모든 텍스트, 라벨, 활성 아이콘은 웹 접근성 지침(WCAG) AA 레벨 이상의 높은 명도 대비를 유지.

### 2. 완전한 한국어 로컬라이제이션 (True Korean Localization)
* **기본 시스템 언어 자동 감지**:
  - macOS(`defaults read -g AppleLanguages` -> `ko-KR`) 및 Windows 환경에서 시작 즉시 한국어로 렌더링.
  - 최상단 리본: `파일`, `홈`, `삽입`, `그리기`, `디자인`, `레이아웃`, `참조`, `편지`, `검토`, `보기`, `개발 도구`, `Zotero`, `도움말`.
  - 백스테이지 메뉴: `홈`, `새로 만들기`, `열기`, `정보`, `저장`, `다른 이름으로 저장`, `인쇄`, `내보내기`, `닫기`, `옵션`.
* **한국어 폰트 폴백 바인딩**:
  - macOS: `Apple SD Gothic Neo` (산돌고딕).
  - Windows: `맑은 고딕(Malgun Gothic)`.
  - Linux: `Noto Sans CJK KR`.
  - 두부(tofu, □) 현상이나 글리프 누락이 일절 발생하지 않도록 폰트 DB 폴백 체인 구축.

### 3. 한글 조합형 IME 무결성 (Hangul IME Composition)
* **조합 중인 음절과 확정 문자 분리**:
  - 한글 입력 시 조합 중인 음절(Composing String)과 확정된 문자(Committed Text)가 분리되어 타이핑 중 글자가 두 번 찍히거나 뒤로 밀리지 않도록 보장.
* **자모 쪼개짐 방지**:
  - 빠른 타이핑 시 초성/중성/종성이 쪼개져 `ㅎ-ㅏ-ㄴ`처럼 분리되는 현상 방지.
* **캐럿 위치 동기화**:
  - 음절 조합 중 백스페이스나 방향키 입력 시 캐럿의 위치가 실제 텍스트 런 오프셋과 100% 일치하도록 유지 (`crates/engine/src/tests/typing.rs`).
