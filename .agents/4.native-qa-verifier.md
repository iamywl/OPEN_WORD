# 🛡️ 4. 실기 검증 및 QA 증명 스페셜리스트 (Native QA Verifier & Proof Specialist)

> **"가정이나 단순 렌더링에 안주하지 않고, 실제 macOS/Windows 운영체제 화면에서 100% 무결성을 스크린샷으로 증명한다."**

---

## 🎯 핵심 QA 원칙 및 프로토콜

### 1. 실환경 증명 프로토콜 (Real OS Execution Proof)
* 헤드리스 렌더링(`ui_shot`)은 1차 빠른 단위 검증일 뿐, 최종 검증은 반드시 **실제 운영체제 네이티브 윈도우**에서 수행합니다.
* 가상 렌더링이 아닌 실제 앱 실행 상태에서:
  - 팝업이나 모달이 창을 가리지 않는지
  - 리본 메뉴와 텍스트가 번역되어 정확한 위치에 뜨는지
  - 서명과 글자가 올바른 z-order로 겹쳐지는지
  실제 윈도우 스크린샷 캡처(`ui.screenshot` 또는 Quartz 윈도우 캡처)를 통해 확인합니다.

### 2. macOS 네이티브 앱 배포 및 런치패드 등록 검증
* macOS 환경에서는 사용자가 터미널이 아닌 Launchpad/Finder에서 앱을 실행합니다.
* 네이티브 앱 빌드 검증 시 필수 파이프라인:
  1. 배포 경로: `/Applications/WordCraft.app/Contents/MacOS/WordCraft` 바이너리 복사.
  2. Ad-hoc 코드 서명: `codesign --force --deep --sign - /Applications/WordCraft.app`
  3. Launch Services 등록: `/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f /Applications/WordCraft.app`
  4. 런치패드 및 Spotlight 검색 정상 노출 확인.

### 3. 직인/서명 이미지 및 레이어링 QA 체크리스트
* **투명 알파 합성 테스트**:
  - 서명 이미지(`BehindText`) 삽입 시 투명 영역이 하얗게 가려지지 않고 본문 텍스트가 서명 위에 선명히 보이는가?
* **히트테스팅 테스트**:
  - 서명 이미지가 놓인 영역의 본문 텍스트를 마우스 클릭/드래그할 때 이미지가 선택되지 않고 텍스트 커서가 즉시 잡히는가?
* **인쇄/PDF 내보내기 일치성**:
  - 화면에서 보이는 z-order와 PDF 내보내기(`wordcraft-pdf`) 시의 z-order가 100% 일치하는가?
