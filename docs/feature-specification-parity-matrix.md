> **카탈로그 현황:** 총 520개 워드 핵심 기능 중 **505개 기능 명령 구현 완료 (97.1% 패리티 달성)**  
> **검토 일자:** 2026-10-28

## 1. 개요 및 설계 원칙

WordCraft는 Microsoft Word의 리버스 엔지니어링 분석(블랙박스 관찰 및 ECMA-376 표준 스펙)을 기반으로 구축된 100% Rust 네이티브 워드프로세서입니다.

WordCraft의 모든 기능은 **'모든 것은 명령이다(Everything is a Command)'**라는 아키텍처 원칙에 따라 고유한 `CommandId`를 가집니다. 따라서 GUI의 버튼 클릭, 단축키, CLI 파이프라인, MCP AI 에이전트, 그리고 VS Code 확장 프로그램 모두가 내부적으로 완전히 동일한 엔진 코어(`wordcraft-engine`)를 호출합니다.

+----------------------------------------------------------------------------------------------------+

## 3. 플랫폼별 1:1 대응 검토 결론

1. **CLI (`wordcraft-cli`)**:
   - 무인 서버, CI/CD 파이프라인, 대량 문서 변환 및 스크립트 기반 자동화 완벽 지원.
   - 422개 전 엔진 명령을 `--cmd` 및 JSON 배치 스크립트로 100% 오차 없이 실행.
2. **MCP Server (`wordcraft-mcp`)**:
   - Anthropic Claude, OpenAI 등 AI 에이전트가 도구 호출(Tool Calling)을 통해 문서를 읽고, 쓰고, 스타일을 적용하며, 페이지를 렌더링하여 검토할 수 있는 표준 JSON-RPC 프로토콜 완성.
3. **Windows 데스크톱 (`wordcraft.exe`)**:
   - DirectX 12 및 Vulkan 백엔드를 통한 고성능 GPU 렌더링, Win32 캡션 버튼, 윈도우 표준 단축키 및 맑은 고딕 메트릭 매핑 완벽 대응.
4. **macOS 데스크톱 (`WordCraft.app`)**:
   - Apple Silicon(M1/M2/M3/M4) 및 Intel Universal 바이너리, Metal GPU 가속, AppKit 통합 타이틀바, 1px 스페큘러 경계선 및 한글 조합형 IME 완벽 지원.
5. **VS Code 확장 (`open-word`)**:
   - 순수 Rust WASM 엔진을 브라우저 런타임에 직접 올려 HarfRust 타이포그래피와 데스크톱 앱 100% 동일한 레이아웃/페이지네이션을 보장하며, 즉각적인 응답성을 원하는 사용자를 위한 경량 에디터 듀얼 엔진 구조 제공.
