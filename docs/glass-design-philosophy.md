# WordCraft 글래스 디자인 철학 (Glass Design Philosophy)

> **상태:** 활성 (Active) · **디자인 시스템 버전:** 2.0 (Glassmorphism & Frosted Glass) · **적용 영역:** `crates/ui-egui`

---

## 1. 개요 (Overview)

WordCraft는 전통적인 오피스 워드프로세서의 무겁고 각진 UI를 탈피하여, 현대적인 **글래스모피즘(Glassmorphism)과 프로스티드 글래스(Frosted Glass / 반투명 아크릴)** 디자인 철학을 채택합니다.

글래스 디자인 철학의 목적은 **"작성 중인 문서(Paper)가 시각적으로 가장 돋보이도록 하면서, 주변 제어 도구(Chrome, Ribbon, Panes, Dialogs)를 가볍고 투명한 유리 질감으로 배치하여 시각적 피로도를 최소화하는 것"**입니다.

```
+---------------------------------------------------------------+
| [Glass Title Bar]  문서 제목 (반투명 크롬 & 빛 반사 엣지)      |
+---------------------------------------------------------------+
| [Frosted Glass Ribbon] 탭 & 도구 모음 (은은한 블러 아크릴)    |
+-------------------+-------------------------------------------+
| [Side Glass Pane] |                                           |
| 문서 탐색 및 스타일 |           [ 문서 본문 Canvas ]            |
| (스모키 글래스 패널) |          선명한 흰색/다크 종이            |
|                   |           (최상의 가독성 유지)             |
|                   |                                           |
+-------------------+-------------------------------------------+
| [Glass Status Bar] 페이지 번호, 단어 수 (반투명 레일 바)       |
+---------------------------------------------------------------+
```

## 2. 5대 핵심 디자인 원칙 (Core Principles)

### ① 반투명성과 깊이감 (Translucency & Layered Depth)
- 타이틀바, 리본 메뉴, 탐색 창, 다이얼로그는 불투명한 단색 플랫 면이 아니라, 뒤의 캔버스 톤을 은은하게 비추는 **반투명 유리(Frosted Glass)** 레이어로 구성됩니다.
- 깊이(Depth)에 따라 여러 층의 레이어가 자연스럽게 겹치며 떠 있는 듯한 플로팅(Floating) 감각을 전달합니다.

### ② 빛을 머금은 하이라이트 경계선 (Specular Edge Highlight)
- 두껍고 둔탁한 테두리 대신, 유리의 단면처럼 빛을 반사하는 **1px 미세 하이라이트 스트로크(Specular Border)**를 적용합니다.
  - **라이트 글래스:** 은은한 화이트 림(`rgba(255, 255, 255, 0.4)`)과 연한 그레이 경계.
  - **다크 옵시디언 글래스:** 다크 틴트 유리 표면과 섬세한 엣지 반사(`rgba(255, 255, 255, 0.12)`).

### ③ 부드러운 다층 확산 그림자 (Soft Ambient Diffusion Shadows)
- 각진 하드 섀도우 대신, 빛이 반투명 유리체를 통과하며 바닥면에 퍼지는 **소프트 앰비언트 블러 그림자(Blur 24px~32px)**를 사용하여 공중에 떠 있는 입체감을 만듭니다.

### ④ 유려한 유기적 곡률 (Fluid Curvature & Rounded Corners)
- 날카로운 직각 모서리를 배제하고, 손에 닿는 유리 조약돌 같은 부드러운 곡률을 적용합니다:
  - **모달 및 윈도우 다이얼로그:** `CornerRadius: 10px ~ 12px`
  - **메뉴 및 팝업:** `CornerRadius: 8px ~ 10px`
  - **버튼 및 입력 필드:** `CornerRadius: 6px`
  - **퀵액세스 및 상태 태그:** 알약형(Pill) 둥근 형태 지원.

### ⑤ 가독성 우선 및 WCAG 대비 준수 (Strict Legibility & Accessibility)
- 글래스 효과가 결코 텍스트 가독성을 해쳐서는 안 됩니다.
- 문서 본문 영역(Paper)은 100% 불투명도를 유지하여 텍스트의 선명도를 완벽히 보장하며, 글래스 UI 위의 모든 텍스트/아이콘은 **WCAG 4.5:1 이상의 높은 명도 대비**를 엄격히 유지합니다.

## 3. 컴포넌트별 글래스 적용 상세

| UI 컴포넌트 | 적용된 글래스 효과 | 시각적 특징 |
|---|---|---|
| **타이틀 바 (Title Bar)** | 울트라 씬 글래스 크롬 | 윈도우 배경과 문서 영역 사이를 부드럽게 연결하는 반투명 상단 바 |
| **리본 툴바 (Ribbon)** | 프로스티드 아크릴 쉘 | 탭 전환 시 부드러운 틴트와 호버 시 은은한 유리 하이라이트 |
| **사이드 패널 (Navigation/Styles)** | 스모키 글래스 패널 | 캔버스와 자연스럽게 분리되면서도 배경의 깊이를 머금는 측면 레일 |
| **팝업 & 콘텍스트 메뉴** | 플로팅 글래스 카드 | 8px 코너 반경과 24px 확산 섀도우를 가진 유려한 플로팅 레이어 |
| **다이얼로그 (Dialogs)** | 옵시디언 / 클리어 글래스 윈도우 | 깊이 있는 32px 앰비언트 섀도우와 미세한 유리 테두리 스트로크 |
| **상태 표시줄 (Status Bar)** | 슬림 글래스 레일 | 하단에 가볍게 밀착되어 정보를 깔끔하게 제공 |

## 4. 토큰 및 비주얼 테마 구현 (`crates/ui-egui/src/theme.rs`)

WordCraft의 글래스 테마는 `Tokens`와 `visuals()` 함수를 통해 제어됩니다:

- `visuals.window_corner_radius`: 부드러운 글래스 윈도우를 위해 `CornerRadius::same(10)` 적용.
- `visuals.menu_corner_radius`: 팝업 메뉴 및 드롭다운을 위해 `CornerRadius::same(8)` 적용.
- `visuals.widgets.*.corner_radius`: 입력 컨트롤과 버튼에 `CornerRadius::same(6)` 적용.
- `visuals.popup_shadow`: `blur: 24, spread: 1`의 글래스모피즘 확산 섀도우.
- `visuals.window_shadow`: `blur: 32, spread: 2`의 입체적 앰비언트 섀도우.
